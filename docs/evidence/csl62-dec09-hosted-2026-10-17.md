### Named suites confirmed run (not skipped)

`pytest -q` prints only aggregate counts — it does not itemize files — so
per-file confirmation is by collection scope plus a skip-marker audit at
`2a73f12`:

- `app/pyproject.toml` sets `testpaths = ["tests"]` and the gate runs
  `python -m pytest -q` with `working-directory: app`, so the whole
  `app/tests` tree is collected.
- `tests/test_invariants.py` (12 tests), `tests/brokers/test_g7_acceptance.py`
  (11), and `tests/system/test_watchonly_durability.py` (25, the BUG-159 D1–D4
  file) all exist at `2a73f12` and contain **no** `pytestmark`/`skip`/`skipif`/
  `xfail` markers; no conftest under `app/tests` sets `collect_ignore` or skip
  hooks. Nothing deselects them, and a failure in any of the 48 tests would have
  failed the job.
- The 115–116 per-cell skips are conditional marks elsewhere (rust-parity files
  when `cockpit_quant` is not yet installed, unavailable sibling-repo provenance
  checks, platform-only cases, missing optional CLIs).

## Gaps (carried, not resolved here)

1. **Hosted ≠ DEC-09.** Hosted Ubuntu 24.04 stands in for local Ubuntu/WSL2 and
   hosted Windows Server 2025 for the operator's native Windows. Accepting these
   as DEC-09 evidence is an unresolved decision owned by Lucas; until amended,
   DEC-09 still requires the local workstation matrix.
2. **`quant` smoke absent.** `python -m quant --strategy market_maker
   --events 20000` (documented in `docs/quant-engine.md`) is not run by
   `run-gates` or any workflow — no hosted cell covers it.
3. **No per-file artifact.** The gates emit aggregate counts only and upload no
   JUnit/artifact output, so "file X ran" rests on collection scope rather than a
   recorded node list. Emitting `--junitxml` and uploading it would close this;
   that is a workflow edit and needs Lucas.
4. **Windows regression after this SHA.** `049b2dc` and `60d1884` (the two
   newest main pushes) fail both hosted Windows cells on
   `test_subprocess_child_does_not_inherit_jev_api_key` (`ExecutableNotFound:
   '/bin/true'` — POSIX path on Windows). Already filed as Linear **CSL-279**
   (assigned to Samir).
5. **No WSL2 cell** exists in hosted CI, and macOS remains nightly/`ci:full`/
   dispatch only — both by design, but they bound what hosted evidence can ever
   cover.
