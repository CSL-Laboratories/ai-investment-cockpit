# CSL-62 hosted four-cell evidence — provisional hosted Blacksmith stand-in

**Status: provisional hosted Blacksmith stand-in. This is not a DEC-09 PASS.**

`DEC-09` ([[REGISTER]]) defines the release-blocking matrix as *local* native
Windows plus Ubuntu/WSL2 × Python 3.11/3.12 on the operator workstation, and
`ci.yml` states hosted jobs are merge diagnostics, not a substitute. The cells
below ran on hosted Blacksmith runners, so this note can only stand in for that
matrix if DEC-09 is amended. Whether to accept hosted Blacksmith cells as DEC-09
evidence is an **unresolved decision owned by Lucas** — not decided here.

Related track: [PR #174](https://github.com/CSL-Laboratories/ai-investment-cockpit/pull/174)
(CSL-221) builds an attempt-pinned six-cell qualification bundle (Linux,

validator and negative controls. If merged and accepted as the hosted evidence
form, that qualification bundle would supersede this stand-in; the same DEC-09
substitution decision owned by Lucas covers both.

## Gaps (carried, not resolved here)

1. **Hosted ≠ DEC-09.** Hosted Ubuntu 24.04 stands in for local Ubuntu/WSL2 and
   hosted Windows Server 2025 for the operator's native Windows. Accepting these
   as DEC-09 evidence is an unresolved decision owned by Lucas; until amended,
   DEC-09 still requires the local workstation matrix.
2. **`quant` smoke absent.** `python -m quant --strategy market_maker
   --events 20000` (documented in `docs/quant-engine.md`) is not run by
   `run-gates` or any workflow — no hosted cell covers it.
3. **No per-file artifact.** The gates emit aggregate counts only and upload no
   JUnit/artifact output, so "file X ran" rests on collection scope rather than a
   recorded node list. Emitting `--junitxml` and uploading it would close this;
   that is a workflow edit and needs Lucas.
4. **Windows `/bin/true` regression after `2a73f12`.** `049b2dc` and `60d1884`
   failed both hosted Windows cells on
   `test_subprocess_child_does_not_inherit_jev_api_key`. Fixed on main by
   [PR #183](https://github.com/CSL-Laboratories/ai-investment-cockpit/pull/183)
   (`a6df41f`, CSL-279); this note now binds a later SHA that includes that fix.
5. **No WSL2 cell** exists in hosted CI, and macOS remains nightly/`ci:full`/
   dispatch only — both by design, but they bound what hosted evidence can ever
   cover.
